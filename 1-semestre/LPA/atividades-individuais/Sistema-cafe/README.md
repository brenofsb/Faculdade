# SistemaCafe

**Disciplina:** LPA - Lógica de Programação  
**Última atualização:** 2026-09-24

## Visão geral
Sistema de gerenciamento de pedidos para cafeterias desenvolvido em Java. O programa permite registrar itens do cardápio, aplicar descontos, processar pagamentos e gerar um relatório final.

## Objetivo
Gerenciar pedidos de uma cafeteria de forma simples, automatizando cálculo de valores, descontos, doações e formas de pagamento.

## Funcionalidades
- Cadastro de itens do menu
- Desconto por quantidade de cookies
- Desconto progressivo do valor total
- Doação opcional para a ONG Zero Fome
- Pagamento em Pix, cartão ou dinheiro
- Cálculo de troco
- Relatório final com total arrecadado e média de doação

## Tecnologias
- Java
- `Scanner`
- Estruturas condicionais
- Estruturas de repetição
- Operações aritméticas

## Como rodar
1. Abra o terminal.
2. Acesse a pasta do projeto:
   ```bash
   cd 1-semestre/LPA/atividades-individuais/Sistema-cafe
   ```
3. Compile:
   ```bash
   javac src/SistemaCafe.java
   ```
4. Execute:
   ```bash
   java -cp src SistemaCafe
   ```
