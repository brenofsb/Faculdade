# POO

**Disciplina:** POO - Programação Orientada a Objetos  
**Última atualização:** 2026-09-25

## Visão geral
A disciplina de POO foi trabalhada com conceitos fundamentais da programação orientada a objetos, como classes, objetos, atributos, métodos e organização de código em módulos.

## Navegação
- [Simulador_tv](./atividades-individuais/simulador_tv)

## Aprendizados principais
- Modelagem orientada a objetos
- Criação e uso de classes
- Organização de código em métodos
- Manipulação de estados e lógica de controle
- Estruturas de dados e fluxo de execução
