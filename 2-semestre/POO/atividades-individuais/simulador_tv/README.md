# Simulador_tv

**Disciplina:** POO - Programação Orientada a Objetos  
**Última atualização:** 2026-09-25

## Visão geral
Sistema em Java para simular o controle de cinco televisões diferentes. Cada TV possui status de ligado/desligado, canal atual e volume, com ações independentes para cada aparelho.

## Objetivo
Modelar um sistema de controle de TVs usando lógica orientada a objetos e estruturas de dados simples.

## Funcionalidades
- Seleção de uma TV entre cinco opções
- Ligação e desligamento de cada TV
- Alteração de canal com lista válida
- Controle de volume com limite mínimo e máximo
- Exibição do status atual da TV

## Tecnologias
- Java
- Arrays bidimensionais
- Métodos
- Estruturas condicionais

## Como rodar
1. Acesse a pasta do projeto:
   ```bash
   cd 2-semestre/POO/atividades-individuais/simulador_tv
   ```
2. Compile o programa:
   ```bash
   javac src/Simulador_tv.java
   ```
3. Execute:
   ```bash
   java -cp src Simulador_tv
   ```
