# menu_de_carnes

**Disciplina:** DFE - Desenvolvimento Front-End  
**Última atualização:** 2026-09-24

## Visão geral
Página estática em HTML para apresentar um menu de carnes em formato simples e visualmente organizado.

## Objetivo
Exibir uma lista de opções de carnes em um layout básico de página web.

## Funcionalidades
- Cabeçalho com título da página
- Lista de itens do menu
- Estilização com CSS
- Estrutura básica de página HTML

## Tecnologias
- HTML
- CSS

## Como rodar
1. Acesse a pasta do projeto:
   ```bash
   cd 2-semestre/DFE/atividades-individuais/"menu de carnes"
   ```
2. Abra o arquivo `src/index.html` em um navegador.
