# minhas_favoritas

**Disciplina:** DFE - Desenvolvimento Front-End  
**Última atualização:** 2026-09-24

## Visão geral
Página estática em HTML que reúne links para sites e conteúdos favoritos do autor, formando uma espécie de página de favoritos pessoal.

## Objetivo
Organizar links importantes em uma página visualmente simples e funcional.

## Funcionalidades
- Título e apresentação inicial
- Lista de páginas favoritas
- Links para conteúdos e canais preferidos
- Imagem ilustrativa
- Estrutura de lista em HTML

## Tecnologias
- HTML

## Como rodar
1. Acesse a pasta do projeto:
   ```bash
   cd 2-semestre/DFE/atividades-individuais/minhas_favoritas
   ```
2. Abra o arquivo `src/minhas_favoritas.html` em um navegador.
