# meu_site

**Disciplina:** DFE - Desenvolvimento Front-End  
**Última atualização:** 2026-09-24

## Visão geral
Página pessoal em HTML e CSS desenvolvida para apresentar uma breve apresentação sobre o autor, com estrutura de cabeçalho, navegação, texto e imagem.

## Objetivo
Criar um site simples de apresentação pessoal com elementos visuais básicos e layout organizado.

## Funcionalidades
- Cabeçalho com título principal
- Navegação com links
- Seção de apresentação pessoal
- Área de interesses
- Rodapé com assinatura
- Estilização com CSS

## Tecnologias
- HTML
- CSS

## Como rodar
1. Acesse a pasta do projeto:
   ```bash
   cd 2-semestre/DFE/atividades-individuais/meu_site
   ```
2. Abra o arquivo `src/meu_site.html` em um navegador.
